# RESET tributário

**R**eforma **E**xplicada **S**em **E**nrolação **T**ributária.

Página em HTML que explica a reforma tributária brasileira (CBS, IBS e Imposto Seletivo) para quem não é do ramo: como é hoje, o que muda até 2033, e o que acontece com MEI, clubes e Pix. Inclui simuladores simples.

Site: https://luizcoura.github.io/reset-tributario/

Para ver localmente, abra `index.html` no navegador. Não há dependências nem etapa de build.

Os números dos simuladores são estimativas didáticas, não cálculo oficial. Confirme com um contador.
